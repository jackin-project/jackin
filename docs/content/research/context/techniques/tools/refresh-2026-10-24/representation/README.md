## Executed result and limits

All **14 local checks passed**. Compact JSON and JSON fields+rows preserved the typed fixture. Plain CSV, TSV and pipe rows lost types and collapsed null with empty strings; versions with JSON-valued cells preserved the fixture. Invalid field widths, duplicate fields, missing-versus-null ambiguity, duplicate JSON keys and duplicate edit anchors were rejected by the probe's own guards. These results do not test upstream host, CSV, TOON or model implementations.

The 18-record, seven-field fixture has booleans, numbers, null, empty strings, leading-zero strings, multilingual values, delimiters, quotes and newlines. Counts include encoded data headers but no additional instruction explaining the format. Typed round-trip equality covers these fixture values, key presence and array order; it is not arbitrary numeric-lexeme preservation, source-byte identity or model comprehension.

The edit fixture compares a one-line change in a deterministic 200-line file: a 95-byte/30-token old+new payload against a 5,524-byte/1,809-token whole-file payload on both proxy encodings. Both produce the expected final bytes locally. This deliberately favorable example does not include model anchor selection, host validation, retries or task acceptance.

Style and language strings are manually authored candidates. Their token counts are reproducible; semantic equivalence and translation/compliance were not evaluated.

Image rows compute documented provider formulas without generating, editing or sending an image. Claude sizing checks match the documented A4, screenshot and 4K examples. OpenAI examples reproduce specific GPT-6 Astra settings; no missing sibling contract is inferred. Gemini dollar columns are arithmetic under a dated rate, not invoices.

## Reproduce in an isolated scratch directory

Use an environment where Python is available. Pin the tokenizer library and record dependency resolution. The first two commands below download a small public package and encoding data; the probe itself disables socket connections before tokenizer loading.

```bash
python -m pip install --disable-pip-version-check --no-cache-dir --target ./python-libs tiktoken==0.12.0

PYTHONPATH=./python-libs TIKTOKEN_CACHE_DIR=./tokenizer-cache python -c \
'import tiktoken; tiktoken.get_encoding("cl100k_base"); tiktoken.get_encoding("o200k_base")'

PYTHONPATH=./python-libs TIKTOKEN_CACHE_DIR=./tokenizer-cache \
python ./representation_probe.py --out ./probe-results
```

Compare fixture/result hashes with `results.json` and the manifest. Do not interpret reproducibility of the synthetic arithmetic as replication of a provider bill or paper benchmark. The small runtime duration in the execution manifest is bookkeeping, not an inference latency measurement.
