## Reproduce the offline probe

From this directory, with Python 3 and no third-party dependencies:

```sh
python cache_scenarios.py
```

The recorded execution used Python 3.12.14 and exited zero. The current manifest is authoritative for the exact execution environment. Expected results include:

- A 1.25× write at read multiplier 0.05 needs one additional read for strict savings versus ordinary input; a 2.5× write needs two.
- The documented Argon boundary scenario costs $0.0052 versus $0.006895 for input only, a 32.596% increase after shortening the aggregate increment. This deliberately excludes changes in generation cost.
- Ten independent normalized writes cost 12.50 units; one useful pioneer plus nine eligible reads at 0.05 costs 1.70; an additional prewarm plus ten reads costs 1.75. No real concurrency, timing or cache receipt was measured.
- The byte fixture shares 20 bytes with a dynamic path first and 4,320 with the same fixed instructions first. Bytes are not model tokens, and reordering instructions can alter authority.
