## Summary

No paid or subscription agent benchmark was run. Current executable evidence consists of isolated source builds, upstream tests, synthetic/producer-generated fixtures, package checks and accounting regressions. Those results resolve implementation questions; they do not establish a six-product performance ranking.

The earlier session decomposition can be checked arithmetically, but its raw receipts and complete style samples were not recovered. Its inferred thinking share, claimed tokenizer equivalences, fixed envelope subtraction and universal economic conclusions are unverified.

## Question and scope

What is the native baseline, which costs are already present, and which earlier observations can be independently reproduced?

## Method

The repository baseline is [Jackin fb9a51c](https://github.com/jackin-project/jackin/tree/fb9a51ca4eb2e51b92abe1c994ac5e469458cd95). The current checkout, uploaded brief, historical PR and retrievable source history were inspected. Private agent settings and transcripts were not searched. The [scope ledger](/research/context/tools/12-scope-and-reconciliation/) records inaccessible history and the real delegated work.

The [measurement instruments](/research/context/techniques/tools/) now require explicit inputs, preserve unknown accounting fields and default to offline request preparation. Their offline regressions check duplicate receipt handling, monotone updates, session/model separation, aggregate cache writes, missing TTLs, true zero costs, invalid receipts, CRLF input and PNG dimensions.

### Conditional arithmetic, not a current workload estimate

Using only the old printed counts and its **historical assumed** rates of $10 fresh input, $12.50 writes, $1 reads and $50 output per million tokens gives:

| Printed class | Tokens | Conditional dollars |
|---|---:|---:|
| Fresh input | 5,475 | 0.0547500 |
| Cache writes, assumed five-minute | 84,693 | 1.0586625 |
| Cache reads | 1,167,417 | 1.1674170 |
| All output | 26,977 | 1.3488500 |
| Total | — | **3.6296795** |

The printed replay count of 12,207 would cost $0.61035 at that output rate. Multiplying that by the old 58.5% style reduction gives $0.35705475, or 9.84% of the conditional total. This is **not measured savings**: the replay count includes tool arguments outside ordinary prose policy, the reduction corpus is incomplete, and policy changes can alter subsequent turns, cache traffic and success.

The original 14,770 residual is simply 26,977 minus 12,207. Its precise arithmetic does not establish a precise reasoning count. Cache-write TTL is another unresolved input: the historical prose elsewhere claims one-hour writes while this table assumes five-minute pricing. The revised scripts keep unknown TTL visible rather than choosing the cheaper rate.

Current product chapters contain fresh component receipts: [Caveman](/research/context/tools/01-caveman-design/), [RTK](/research/context/tools/03-rtk-design/), [LeanCTX](/research/context/tools/04-leanctx-design/), [Ponytail](/research/context/tools/09-ponytail-design/), [Headroom](/research/context/tools/02-headroom-design/) and [LemonCrow](/research/context/tools/10-lemoncrow-design/).

None is an invoice or a quality-adjusted task outcome. Timings from this shared research container are smoke measurements, not controlled cold/warm latency comparisons.

### Establishing the next native baseline

Record the exact agent binary, auth route, model and effort, system/role instructions, native tools, loaded schema set, permissions, timeouts, repository commit and dirty patch. Record which hooks actually fire, which bytes reach the model and whether the host requires a native read before editing. Keep existing native caching, compaction, schema discovery and edit tools enabled where they are part of the chosen baseline.

Start with explicit isolated agent homes and fresh session IDs. Separate cold versus warm indexes and caches; never call warm startup “free.” Export provider usage, all retries/child sessions, task patches and independent grader receipts. Observe quota windows directly for subscription arms. The [validation protocol](/research/context/techniques/16-validation-harness/) defines acceptance and sampling.

## Implications for jackin❯

Remove duplicate injections only after proving both registrations and observing the resulting single delivery. Prefer exact bounded retrieval, edit-over-rewrite and concise complete instructions, with normal escape paths for full reads and rewrites. Preserve selected model/effort. These are concrete implementation priorities, not measured multipliers or claims of zero possible risk.

## Limitations and unknowns

No recovered private transcript supports a new dollar profile. No present local-token estimate is substituted for Anthropic billed usage. Old numerical tables can support conditional arithmetic and fixture design; current promotion requires a new baseline and the exact proposed treatment.
