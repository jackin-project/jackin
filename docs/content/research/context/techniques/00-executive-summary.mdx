## Summary

Cutoff **2026-10-24T01:15:00Z**; verified October 24. **Optimize accepted tasks, beginning with the native baseline and precise context selection. Preserve correctness, selected model and reasoning effort.** Package useful low-impact policy automatically, then qualify one narrow filter or retrieval capability at a time. [Concrete profiles](/research/context/tools/), [implementation stages](/research/context/engine/10-rollout-and-validation/).

The old dossier's universal 2.4–2.5× ceiling, conditional 5–6.2× forecast, unconditional “no honest 10×,” and riskless day-one savings are withdrawn. Their original local transcripts and complete sample corpus were not recovered, current provider contracts differ, and routing/effort changes were mixed with compression. Neither promise nor exclude a multiplier without a defined workload and a matched baseline.

## Question and method

Which mechanisms reduce total cost, quota pressure, latency or context occupancy without sacrificing accepted-task quality? Reopen primary implementations and provider contracts, reproduce cheap decisive fixtures, recompute accessible historical data, and retain uncertainty where real-host or paid execution is absent. The [baseline audit](/research/context/techniques/02-baseline-audit/) and [coverage ledger](/research/context/tools/12-scope-and-reconciliation/) identify unsupported historical numbers rather than treating them as current observations.

## Workload-specific ceilings

Let a treatment address fraction `f` of baseline total cost and reduce that fraction to ratio `r`, with normalized added overhead `h`. Under an explicitly fixed trajectory, the remaining cost ratio is `1 − f + f × r + h`; its reciprocal is the modeled speedup in cost. This is arithmetic, not a prediction that trajectories or acceptance remain fixed.

For example, **if** eligible observations are 10% of total spending and become ten times smaller without price-class changes, the ratio is 0.91 before overhead: about 1.10× total improvement. If a very wasteful workflow spends most of its resources on avoidable attempts, eliminating that waste can support a much larger multiplier. Both examples require task-specific evidence. Cache writes, output/reasoning, retries, local inference and operator time can change the result. [Composition arithmetic](/research/context/techniques/15-composed-stacks/).

The former 32/29/20/17/2 workload split, 54.8% inferred thinking share, 86.3% caching estimate and 58.5% style sample are historical claims with unavailable original receipts or incomplete reproduction sets. They cannot establish the current workload or a universal bound. Subtracting proxy-tokenized visible output from a provider output counter does not reliably recover hidden reasoning.

## Material evidence changes

Current component findings overturn several earlier assumptions: Caveman's Apache engine changes reuse options; RTK now has an API and stdin filter with edition-specific licenses; Headroom's Rust no-ML build succeeds but fidelity/persistence issues remain; LeanCTX exposure stubs require lifecycle control; LemonCrow 0.8 distinguishes public Lite from private advanced intelligence. Exact versions and probes are in the [release register](/research/context/tools/08-current-release-register/).

Independent evidence is heterogeneous. Old JetBrains/Quesma studies cannot rank today's six releases. A current RTK external test is small and host-dependent. LemonCrow's historical Terminal “fresh input” headline includes cache writes in its baseline; its normalized-price scenario is a separate calculation. Competitor-operated comparisons, fixed-trajectory replays, observational usage and payload fixtures are labeled accordingly. [Evidence ledger](/research/context/tools/07-evidence-and-claims/).

CAVEWOMAN's paper and expanded repository use different model/result denominators. Notation Matters reports format savings alongside accuracy losses. Self-hosted KV compression changes serving memory and latency, not automatically hosted billed tokens. New TurnCost and CompactionBench/APEC evidence informs experiments but does not qualify a current Jackin optimizer. [Literature](/research/context/techniques/24-fresh-literature-and-market-delta/).

## Claims retired or narrowed

| Earlier shortcut | Current disposition |
|---|---|
| Every output token equals fifty cache-read tokens | Depends on exact model, provider, tariff and billing route; use current class prices. |
| Compact/clear, schema reduction or memory is always quality-neutral | Changes available evidence and tool behavior; measure recall and acceptance. |
| Any smaller input saves quota | Subscription denominators and native credit rules differ from API prices. |
| JSON/TOON/TRON/CSV has one best compression ratio | Typed round trip, schema/protocol overhead, tokenizer and model comprehension matter. |
| Image/PDF costs have one fixed formula or universal multiplier | Model, detail, tiling/patch limits, image bounds and PDF text-plus-image rules vary. |
| A model switch or lower effort is a compression gain | Separate policy intervention; keep it outside the main arm. |
| Recovery means lossless model behavior | Exact originals can be available while the agent confidently misses an omitted fact. |
| Nonsignificant quality difference proves equivalence | Requires a predeclared margin and a sufficiently precise paired/task-cluster confidence bound. |

## Adoption and smallest decisive tests

Implement configuration ownership and a short precise-read/clarity policy; validate delivery, precedence and off/resume behavior without paid inference. Add scoped capture, durable authorized recovery and epochs. Then demonstrate actual host replacement, native read-before-edit receipts, cancellation, faults and parallel worktrees for one filter family. Only afterward run the authorized current-task comparison, native versus component arms, with independent graders and all-attempt accounting.

The proposed complex-optimizer gate requires zero observed critical regressions, a one-sided 95% acceptance lower bound above −1 percentage point, a strong all-attempt cost-per-accepted-task benefit, and bounded p95 task latency. The one-point margin is uncertainty tolerance, not permission for known quality loss. A 12–30-task pilot finds defects and estimates variance; it is not proof of equivalence. [Canonical protocol](/research/context/techniques/16-validation-harness/).

## Limitations

No paid/subscription agent tasks, live host result replacement or quota-depletion trials were executed. Local build/probe outcomes and accessible benchmark recomputations are real but narrower. Current recommendations are strongest for architecture, evidence handling and experiments; comparative task gains remain unmeasured. Missing source/receipts are named rather than replaced with attractive forecasts.
