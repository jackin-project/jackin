### Scope boundaries

All six products are decomposed into instructions, shell filtering, native observations, retrieval, history/memory, provider proxy, local inference, and representation. Techniques include baseline behavior, token-class economics, output/style, precise reads/edits, schemas, caching, delegation, multimodal context, quotas, latency, fleets, online quality, effort and model routing. The last two remain separate interventions with an unchanged main comparison policy.

Jackin integration covers configuration and role ownership, images and agent homes, hooks/MCP, execution/editing/approvals, usage/authentication, session lifecycle, worktrees, state retention and cleanup. Each proposed capability needs an owner and a measured interception boundary.
