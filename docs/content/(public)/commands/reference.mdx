This page holds the output of `jackin <command> --help` for every command. `--gateway` is a global option and every command accepts it.

## jackin

```text
Run Codex in OpenShell sandboxes

Usage: jackin [OPTIONS] [COMMAND]

Commands:
  gateway    Manage the jackin gateway entries
  export     Fetch the sandbox branches into the host repository
  stop       Stop a sandbox
  start      Start a stopped sandbox
  purge      Delete a sandbox; refuses unexported work without --force
  account    Manage accounts and their bindings
  doctor     Check the host tools, the gateway, and the engine socket
  build      Build the role image and print its image ID
  load       Build the image if needed, launch a sandbox, and attach to Codex
  attach     Reattach to the Codex terminal of a sandbox
  agent      Manage agent instances in a sandbox
  integrate  Merge each agent branch into the lead branch in the sandbox
  shell      Open a new shell in a sandbox
  ls         List the jackin sandboxes
  usage      Show the limit windows of each account
  inspect    Show a sandbox, its labels, providers, and policy status
  role       Manage role sources
  workspace  Manage workspaces
  help       Print this message or the help of the given subcommand(s)

Options:
      --gateway <GATEWAY>  Gateway name from the jackin config
  -h, --help               Print help
  -V, --version            Print version
```

### jackin gateway add

```text
Add a gateway entry

Usage: jackin gateway add [OPTIONS] <NAME>

Arguments:
  <NAME>  Name of the gateway as registered with openshell gateway add

Options:
      --gateway <GATEWAY>            Gateway name from the jackin config
      --workspace <WORKSPACE>        OpenShell workspace that jackin uses [default: default]
      --builder <BUILDER>            Docker buildx builder with the docker driver [default: default]
      --platform <PLATFORM>          Image platform; defaults to the host architecture [possible values: linux/arm64, linux/amd64]
      --engine-port <ENGINE_PORT>    Port of the dedicated Docker engine on host.openshell.internal
      --engine-certs <ENGINE_CERTS>  Directory with the engine client ca.pem, cert.pem, and key.pem
      --default                      Make this the default gateway
  -h, --help                         Print help
```

## jackin load

```text
Build the image if needed, launch a sandbox, and attach to Codex

Usage: jackin load [OPTIONS] [ROLE] [PATH]

Arguments:
  [ROLE]  Role name; defaults to the workspace default role
  [PATH]  Project directory [default: .]

Options:
      --account <ACCOUNT>              Account to use for this launch
      --gateway <GATEWAY>              Gateway name from the jackin config
      --agent <AGENT>                  Agent to run for this launch; repeat for more instances
      --provider <PROVIDER>            Provider to use for this launch
      --provider-for <AGENT=PROVIDER>  Provider for one instance
      --account-for <AGENT=ACCOUNT>    Account for one instance
      --model-for <AGENT=MODEL>        Model for one instance
      --model <MODEL>                  Model to use for this launch
      --task <TASK>                    Task text for the instances
      --task-file <TASK_FILE>          Host file that holds the task text
      --issue <ISSUE>                  GitHub issue URL that holds the task
      --rebuild                        Build the image again
      --launch-id <LAUNCH_ID>          Continue an earlier launch
      --env <NAME=VALUE>               Value for a role env entry
  -h, --help                           Print help
```
