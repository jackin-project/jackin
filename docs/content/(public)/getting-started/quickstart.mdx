<EarlyDevelopmentNotice />

This page takes you from a running gateway to a Codex session in a sandbox. You need the tools from [Install jackin](/getting-started/installation/) and a role repository. To write a role, see [Create a role](/developing/creating-roles/).

## Before you start

- A gateway is running and registered with `openshell gateway add`. See [Run a local OpenShell gateway](/guides/gateway/). The steps below use the name `jackin-local`.
- You have a project in a git repository, for example `~/Projects/my-app`.
- You have a Codex login on this machine, in `~/.codex`.

## Launch Codex

<Steps>
<Step>

Add the gateway to the jackin configuration and make it the default:

```sh
jackin gateway add jackin-local --default
```

The command only writes the jackin configuration. It does not contact the gateway.

</Step>
<Step>

Check the host and the gateway:

```sh
jackin doctor
```

Fix every `fail` line before you go on.

</Step>
<Step>

Add the role. The source is a directory or the URL of a git repository:

```sh
jackin role add my-role ~/roles/my-role
jackin role check ~/roles/my-role
```

`jackin role check` prints nothing when the role is valid.

</Step>
<Step>

Add your Codex login as an account:

```sh
jackin account add codex --name work --chatgpt-from ~/.codex
```

Jackin reads the login and stores its refresh material in an OpenShell provider on the gateway. See [Accounts](/guides/accounts/).

</Step>
<Step>

Save the project as a workspace:

```sh
jackin workspace add my-app ~/Projects/my-app
```

</Step>
<Step>

Launch from the project directory:

```sh
cd ~/Projects/my-app
jackin load my-role
```

The directory must be the path you saved. Jackin builds the role image, creates a sandbox, uploads the project, runs the role hooks, starts Codex, and attaches your terminal.

</Step>
</Steps>

Because the workspace has one Codex account, jackin selects it. With more accounts, see how jackin [selects the account](/guides/accounts/#account-selection).

## Leave and return

Press `Ctrl-D`, or `Ctrl-P` then `Ctrl-Q`, to detach. Codex keeps running. To list your sandboxes and reattach:

```sh
jackin ls
jackin attach <sandbox>
```

## Get your work back

Codex works in a copy of your project. Your working tree stays unchanged. Fetch the work into your repository as branches:

```sh
jackin export <sandbox>
```

Then delete the sandbox:

```sh
jackin purge <sandbox>
```

`jackin purge` refuses to delete a sandbox that holds work you have not exported. See [Work with sandboxes](/guides/sandboxes/).
