Jackin runs on your host and talks to an OpenShell gateway that you run. This page installs jackin and the tools it starts. It does not install the gateway. See [Run a local OpenShell gateway](/guides/gateway/) for that.

## Host tools

Jackin starts these programs on your host:

| Program | Used for |
|---|---|
| `openshell` | Registers the gateway, and uploads and downloads files. Install the version that `compatibility.lock.toml` pins (0.1.7). |
| `ssh` | The file transfers of `openshell`. |
| `git` | Filtering the upload and creating the export bundle. It must support `git bundle --no-lazy-fetch`. |
| `docker` | Builds the role images with `docker buildx`. Jackin does not use it for anything else. |
| `op` | Optional. Resolves `op://` references on the host for usage checks. |

Install `openshell` with Homebrew:

```sh
brew install openshell
```

Jackin builds images with Docker BuildKit through `docker buildx`. It needs a buildx builder with the `docker` driver. A `docker-container` builder does not work, because it cannot read a local `docker-image://` context. The gateway entry names the builder, and the name defaults to `default`. See `jackin gateway add --builder`.

## Build jackin from source

The repository pins its toolchain with mise. Clone it, install the tools, and build:

```sh
git clone https://github.com/jackin-project/jackin.git
cd jackin
mise install
mise exec -- mbx +1.99.1 build -p jackin --release
```

The binary is `target/release/jackin`. Copy it to a directory on your `PATH`.

## Check the setup

Run `jackin doctor` after you register a gateway:

```sh
jackin doctor
```

It prints one line for each check. A `warn` or `fail` line ends with `fix:` and the action to take.

| Check | Passes when |
|---|---|
| `openshell-binary` | The `openshell` binary runs. |
| `ssh-binary` | The `ssh` binary runs. |
| `git-binary` | The `git` binary runs and is new enough. |
| `gateway-registered` | The jackin gateway entry exists in the OpenShell registry. |
| `gateway-health` | The gateway answers. |
| `pinned-version` | The gateway version equals the pinned version. |
| `engine-socket` | The Docker engine socket exists. It is `/var/run/docker.sock`, or the `unix://` path in `DOCKER_HOST`. |

`jackin doctor` does not start or repair the gateway. It exits with status 0 when no check fails.

## Where jackin keeps its files

| Path | Content |
|---|---|
| `~/.config/jackin/config.toml` | Gateways, accounts, roles, and workspaces. `$XDG_CONFIG_HOME` replaces `~/.config`. |
| `~/.cache/jackin/` | Role checkouts, image build files, and export staging. `$XDG_CACHE_HOME` replaces `~/.cache`. |

Jackin never changes the active gateway in the OpenShell registry. It passes the gateway name on every call.
