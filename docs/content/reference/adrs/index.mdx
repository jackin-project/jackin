Architecture Decision Records (ADRs) document significant design choices: what was decided, why, and what the trade-offs are. The target design of jackin on OpenShell is in <RepoFile path="rewrite/DESIGN.md">DESIGN.md</RepoFile>. Where an ADR disagrees with it, DESIGN.md is correct.

## Active ADRs

- **[ADR-001: Single-crate vs Cargo workspace](/reference/adrs/adr-001-single-crate-vs-workspace)**
- **[ADR-002: Latest stable Rust toolchain policy](/reference/adrs/adr-002-rust-toolchain)**
- **[ADR-003: Ratatui as the TUI rendering library](/reference/adrs/adr-003-ratatui)**
- **[ADR-004: Capsule pane-body rendering mechanism](/reference/adrs/adr-004-pane-body-rendering)**
- **[ADR-006: EditorState owns concrete workspace config](/reference/adrs/adr-006-editor-state-workspace-config)**
- **[ADR-008: Launch never reconnects to a live instance](/reference/adrs/adr-008-launch-never-reconnects-live-instance)**: a launch creates a sandbox or restores one, and never silently attaches to a running one.
- **[ADR-009: Role hooks are the role author's domain](/reference/adrs/adr-009-role-hooks-authors-domain)**: a hook failure stops the launch.
- **[ADR-010: Cleanup requires explicit operator approval](/reference/adrs/adr-010-cleanup-explicit-operator-approval)**: jackin never deletes a sandbox with unexported work without explicit confirmation.
