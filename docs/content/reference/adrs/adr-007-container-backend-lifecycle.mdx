**Status**: Superseded by <RepoFile path="rewrite/DESIGN.md">DESIGN.md</RepoFile> (decision D22). OpenShell is the only execution engine, and jackin runs no containers itself (D01).  
**Date**: 2026-07-04  
**Deciders**: Operator + agent

## Decision

Persisted-instance lifecycle commands dispatched through a `ContainerBackend` trait, while launch stayed specific to each backend.

## Why it no longer applies

The trait existed to manage instances on more than one local backend. Jackin now creates every sandbox in OpenShell and finds it again by its labels. It keeps no instance manifest and has no backend to select. The `Gateway` trait in `jackin-openshell` replaces the trait of this record.
