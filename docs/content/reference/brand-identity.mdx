# Brand Identity

jackin❯ uses a terminal-native wordmark: the lowercase monospace word `jackin` in white, followed by a green `❯` chevron, on a transparent background. No block, no rounded corners.

## One source of truth

The mark is **generated**, never hand-drawn. The chevron geometry lives in <RepoFile path="docs/scripts/brand-geometry.ts" />. <RepoFile path="docs/scripts/gen-brand.ts" /> writes SVG marks and icon files, and `gen-og` writes social and README images:

```sh
bun run gen-brand
bun run gen-og
```

`gen-brand` always rewrites SVG files and `site.webmanifest`. It creates PNG and ICO files when they are missing, and leaves existing raster files unchanged. Run `bun run gen-brand --raster` to rewrite existing PNG and ICO files.

Never redraw the word or chevron by hand in a component, SVG, or script. To change the chevron, edit `brand-geometry.ts`, then run both commands above. To update existing PNG and ICO files, add `--raster` to the `gen-brand` command. The SVG wordmark outlines its letters. The PNG wordmark renders text with JetBrains Mono.

## Text Forms

There are four valid brand text forms:

| Form | Use |
|---|---|
| `jackin❯` | Primary product and project name in rich text |
| `j❯` | Compact prompt, favicon, app icon, and monogram surfaces |
| `jackin>` | Plaintext fallback when `❯` cannot render |
| `j>` | Compact plaintext fallback when `❯` cannot render |

Literal commands, binaries, crates, packages, environment variables, config keys, file paths, labels, selectors, URLs, and code identifiers stay `jackin` where the operator must type or match that exact value.

## Logo Lockup

The wordmark is white `jackin` (JetBrains Mono Bold) and the green `❯` chevron. The SVG lockup outlines the letters. The PNG wordmark renders the letters as text. The grey `by tailrocks` byline uses **Inter** and aligns its right edge with the word's right edge. The generated wordmark and lockup SVGs both include the byline. The compact `j❯` monogram (square icons) omits it. Do not append `by tailrocks` to ordinary prose, command examples, package names, or code identifiers.

## Color

| Token | Hex | Use |
|---|---:|---|
| Logo word | `#FFFFFF` | The `jackin` word / `j` letter. In the DOM it tracks the theme foreground (`--jk-text`); exported assets use white on dark |
| Logo chevron | `#5CF07A` | The green `❯` chevron |
| Muted accent | `#1D9E75` | UI accent when pure phosphor is too strong; never part of the mark |
| Dark canvas | `#0A0A0A` | Background for icons and social cards (the wordmark itself sits on a transparent background) |

The wordmark has a transparent background — no block. Square caps only: terminals cannot round corners, so neither does the mark or any UI surface. Never recolor the word green, never make the word and chevron the same color, never re-introduce the block on the wordmark.

## Type

The SVG mark uses **JetBrains Mono Bold** outlines, never SVG `<text>`. The PNG wordmark renders `jackin` as text with JetBrains Mono. Supporting prose uses Inter or the system sans-serif stack.

## Terminal Prompt

jackin❯-owned shells use `j❯` as the prompt sigil:

```text
j❯
codex j❯
```

In a terminal the chevron is the `❯` glyph rather than the geometric caret — a TTY can't draw paths, so the glyph is the proven medium fallback (same class as the `jackin>` plaintext fallback).

## Assets

Committed brand assets live under `docs/public/`, all produced by the generators above:

| Asset | Source |
|---|---|
| `favicon.svg` / `favicon.ico` | `j❯` monogram on a dark square |
| `apple-touch-icon.png` | `j❯` monogram, 180 px |
| `icon-192.png` / `icon-512.png` | PWA monogram icons |
| `brand/jackin-wordmark.svg` | SVG wordmark with outlined letters, transparent background — used by BrandMark and the TOC |
| `brand/jackin-wordmark.png` | PNG wordmark with rendered text and the grey `by tailrocks` byline, transparent background |
| `brand/jackin-monogram.{svg,png}` | standalone `j❯` monogram (no byline), transparent background |
| `og-image.png` / `og-image-github.png` | dark social cards with the full lockup |
| `readme-hero.svg` / `readme-hero.png` | static README hero banner |

Run `bun run gen-brand` to regenerate the SVG files and manifest. Run `bun run gen-brand --raster` to also rewrite existing PNG and ICO files. Run `bun run gen-og` to regenerate social and README images. These outputs use the chevron geometry from `brand-geometry.ts`; their word rendering can differ by format.
