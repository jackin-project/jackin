## Implementation sequence and proof

1. **Account ownership.** In `jackin-usage`, give every connection an opaque immutable ID. Persist display metadata, remote identity, scope, ordering and preferences independently from a versioned credential slot in a jackin-specific OS vault. Keep hub management credentials under separate keys. Validate candidate credentials first. Under an interprocess mutation lock, recheck identity, duplicate criteria and cancellation, stage the credential in a fresh slot, and commit metadata pointing to that slot. Clean up abandoned slots on failure and restart. On removal, invalidate the account generation before cleanup. Report vault failures with a recovery action. Specify committed-but-unsynced writes separately from rejected writes so rollback cannot discard the credential of a visible account. Update D25/D26 to permit renewal only for an explicitly connected usage account. Exercise two CLI processes replacing, refreshing and removing one account while another account remains usable. Check the config, binding decisions and gateway inventory before and after. [Jackin design](../../rewrite/DESIGN.md) · [Reference account store](https://github.com/robinebers/openusage/blob/53f70b396698656cb5e1e3f59c40d1b86d6b5296/Sources/OpenUsage/Stores/AccountStore.swift)
2. **Interactive authentication.** Introduce one attempt per pending Add or Sign In Again. A provider driver publishes browser, device, key, selection and validation prompts. The CLI and console observe the same attempt and supply actions. Dropping an attempt releases the listener and stops polling. A generation check guards the final save against late replies. Keep authorization origins fixed by the driver, bind callbacks to loopback, enforce the provider’s path and state, and use its PKCE verifier. Device codes appear before the Open Browser action. Apply the reference’s provider-specific fallback, renewal and workspace rules. Test cancellation while the callback is listening, after validation, and during retry. Test invalid state, expiry, denial, slowdown, duplicate input, blocked listener and unavailable storage through observable account and listener state. [Reference login flow](https://github.com/robinebers/openusage/blob/53f70b396698656cb5e1e3f59c40d1b86d6b5296/Sources/OpenUsage/Views/AddAccountFlow.swift)
3. **Provider reads.** Adapt existing provider crates to validated credentials and add Muse and MiMo clients. Preserve stable resource IDs separately from human-readable labels. Use typed plan, window, balance, budget, activity and reset records. Track missing, zero and partial reads explicitly. Secondary reads have independent success timestamps and retry rules. For each provider, exercise every matrix row against a deterministic network fixture, including incomplete and denied responses. Reauthentication of a known OAuth identity must check all scope components before installing a candidate. Record actual live checks separately. [Provider reference](https://github.com/robinebers/openusage/blob/53f70b396698656cb5e1e3f59c40d1b86d6b5296/docs/providers.md)
4. **Refresh and persistence.** Build a shared scheduler around the existing bounded fan-out and clock. Schedule launch, wake, manual, timer, add and post-redemption passes. Apply the five-minute cadence, ten-minute stale indicator, two-minute per-account deadline, secondary-read timing, offline retries and provider retry holds. Retain last-good values and the latest failure separately. Serialize credential renewal with replacement per account across CLI and console processes. Re-read current generation before each mutation. Use an offline snapshot reader shared by both surfaces. Verify restart, UTC rollover, HTTP-date and delta Retry-After, manual refresh during a hold, late replies after timeout/removal and recovery after an optional read fails. [Refresh contract](https://github.com/robinebers/openusage/blob/53f70b396698656cb5e1e3f59c40d1b86d6b5296/docs/refreshing.md)
5. **Reset and hub services.** Model reset inventory and eligibility independently from the action to spend one. Require explicit confirmation, re-read eligibility, submit once and refresh. Store a hub’s own ID, URL and vault reference. Reconcile remote logins by stable hub identity, restricted to Claude, ChatGPT and Grok. Handle management-key replacement, unavailable hubs and removed remote logins. Test that normal refresh never spends a reset and local removal never alters the remote login. Route provider exchanges and hub requests through the selected HTTP, HTTPS or SOCKS5 proxy. Keep proxy credentials in the vault and redact diagnostics. [Hub lifecycle](https://github.com/robinebers/openusage/blob/53f70b396698656cb5e1e3f59c40d1b86d6b5296/docs/cliproxyapi.md) · [Proxy contract](https://github.com/robinebers/openusage/blob/53f70b396698656cb5e1e3f59c40d1b86d6b5296/docs/proxy.md)
6. **Terminal and CLI.** Extend the pinned baseline’s account and usage pages and its effect/message contract, then update jackin’s dependency pins. Keep the existing console loop and map network/vault work through its asynchronous bridge. Provide the full keyboard path from Accounts to Add Account to a validated first snapshot. Support replacement, reorder, hide, undo, pin, expand, detail history, attention recovery, reset confirmation and a concealed shareable report. Project Priority and All Usage from the same state. Keep the source’s grouping order, pace calculation, thresholds, recovery, notification deduplication and currency-aware account unification. Implement the CLI verbs in the existing argument tree. Cached export reads only persisted metadata and normalized snapshots with documented filter, time, exit and error semantics. Drive keyboard-only flows at normal and narrow widths. Verify JSON and human views after terminating the fixture server and denying vault access. [Dashboard](https://github.com/robinebers/openusage/blob/53f70b396698656cb5e1e3f59c40d1b86d6b5296/docs/dashboard.md) · [CLI contract](https://github.com/robinebers/openusage/blob/53f70b396698656cb5e1e3f59c40d1b86d6b5296/docs/cli.md)
7. **Documentation and attribution.** Update the published account/usage guides, CLI schema and developer material with platform-specific vault behavior, headless limitations, terminal notification policy and keyboard walkthroughs. Preserve the upstream MIT copyright and permission notice for ported work, with paths and attribution in the repository’s notice and REUSE metadata. Maintain per-provider evidence for fixture and live coverage. Record each external limitation and the capability it blocks.
