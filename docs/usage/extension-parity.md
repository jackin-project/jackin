# Usage providers beyond the OpenUsage reference

Audit baseline, 22 November 2026. The four providers below extend [OpenUsage at 53f70b3](https://github.com/robinebers/openusage/tree/53f70b396698656cb5e1e3f59c40d1b86d6b5296). The baseline column describes [jackin at 1b8a6f8](https://github.com/jackin-project/jackin/tree/1b8a6f85c5f0ba0d7e25b406e0850f7abc8533a8). Protocol research used published documentation and the pinned official client revisions linked below. No authenticated live reads were performed for this audit.

| Provider and operation | Provider contract | Baseline and required implementation | Acceptance evidence needed |
|---|---|---|---|
| Kimi connection and renewal | Choose mainland China or global. Form POST `/api/oauth/device_authorization` with a client ID. Present user code and verification URI. Poll `/api/oauth/token` with the device-code grant. The refresh grant uses the same token endpoint. The regional auth/API host pairs are `auth.kimi.com` and `api.kimi.com`, or `auth.kimi.ai` and `api.kimi.ai`. Read `/coding/v1/me` for user_id, nickname, region and optional global_id. [Device grant](https://github.com/MoonshotAI/kimi-code/blob/83e4dde93453dd22e89da03d2c96d84999e7d0c2/packages/oauth/src/oauth.ts) · [regions](https://github.com/MoonshotAI/kimi-code/blob/83e4dde93453dd22e89da03d2c96d84999e7d0c2/packages/oauth/src/region.ts) · [profile](https://github.com/MoonshotAI/kimi-code/blob/83e4dde93453dd22e89da03d2c96d84999e7d0c2/packages/oauth/src/managed-userinfo.ts) | The [Kimi client](../../crates/usage/jackin-usage-provider-kimi/src/lib.rs) accepts supplied credentials and rejects expired login data. The official CLI's client registration is documented in [its configuration](https://github.com/MoonshotAI/kimi-code/blob/83e4dde93453dd22e89da03d2c96d84999e7d0c2/packages/oauth/src/constants.ts). Acceptance for an independently registered jackin client remains unverified. | Pending. Exercise both regions, user refusal, expiry, delayed success after cancellation, same subject in another region, changed subject on reconnect and concurrent renewal. |
| Kimi metrics | Bearer GET `/coding/v1/usages`. Each of limit_5h, limit_7d, limit_month_total and limit_month_code has a used ratio and optional reset. | MiniMax connection and renewal | Subscription page provides a Token Plan key and authenticated quota read. Official clients select global or China. API-key credentials starting with sk-api- address the pay-as-you-go balance product. OAuth credentials use the plan endpoint even when the access token shares that prefix. The official device flow POSTs to /oauth2/device/code with S256, state and the openid, profile and coding_plan scopes. Check the echoed state. Poll /oauth2/token with user_code and the verifier. The interval is milliseconds and expired_in is an absolute Unix millisecond timestamp. Renew against the same token endpoint. [Subscription](https://platform.minimax.io/subscribe/token-plan) · [routing](https://github.com/MiniMax-AI/cli/blob/ae29aae57b05c2140c7ea6aba0a852763ffe7859/src/client/endpoints.ts) · [OAuth](https://github.com/MiniMax-AI/cli/blob/ae29aae57b05c2140c7ea6aba0a852763ffe7859/src/auth/oauth.ts) | [MiniMax client](../../crates/usage/jackin-usage-provider-minimax/src/lib.rs) hardcodes global hosts. Add region and credential-kind metadata, masked plan-key entry with direct validation and key replacement. Use the official client's regional quota endpoints on api.minimax.io and api.minimax.cn. [Endpoint regression tests](https://github.com/MiniMax-AI/cli/blob/ae29aae57b05c2140c7ea6aba0a852763ffe7859/test/client/endpoints.test.ts) | Pending. Test wrong-product, revoked, rejected-in-body, zero-quota and same key twice. Regional credentials must stay on the selected host. |

| MiMo connection and credits | Choose the cluster shown in Token Plan (China, Singapore or Europe). A dedicated tp- key authorizes GET `/v1/platform/token_plan`. Successful authenticated reads still need a live test on each cluster. |
| MiMo balance and history | A regular sk- key can query `/v1/platform/balance` for cash, gift, frozen, credit and available amounts with currency. Daily consumption and bill queries require a regular key. Dates are inclusive UTC days spanning at most 31 days. Both APIs return all records in one response and cover dates from 1 September 2026. Preserve per-model or plugin counts and per-currency bill rows. | Gemini quotas | POST `v1internal:loadCodeAssist` then `v1internal:retrieveUserQuota` with the chosen project on cloudcode-pa.googleapis.com. Retain modelId, tokenType, remainingAmount, remainingFraction and resetTime where present. [Server](https://github.com/google-gemini/gemini-cli/blob/eecccfcd5aff25de5e78135ca20f7abe3f566955/packages/core/src/code_assist/server.ts) · [types](https://github.com/google-gemini/gemini-cli/blob/eecccfcd5aff25de5e78135ca20f7abe3f566955/packages/core/src/code_assist/types.ts) | Baseline joins token type to the label, requires remainingFraction and omits remainingAmount. For each extension, the Accounts screen and interactive CLI must own the same local account and use the same cached snapshot. A terminal walkthrough must connect, refresh, reconnect or replace, rename and remove each account, including a failed replacement that retains the previous connection. Dashboard ordering, hidden metrics, warning preferences and notification recovery apply to eligible typed resources. Cached JSON must expose the last successful observation and its timestamp without accessing a vault or network. These cross-provider acceptance checks remain pending.

## Implementation and verification

| Provider | Native entry point | Evidence and limits |
|---|---|---|
| Kimi | Add a Kimi Code Console key and choose global or China. The candidate key must read the regional quota API before jackin saves it. The backend also implements device-code polling and rotating refresh with an explicit OAuth client registration. [Connection](../../crates/usage/jackin-usage/src/connected.rs) · [official third-party authentication instructions](https://www.kimi.com/code/docs/en/) | The four usage windows stay independent. The optional wallet preserves exact provider units, zero balances and charge-currency fields. Hermetic tests cover account identification, renewal, cancellation, slowdown and expiry. Jackin’s own Kimi OAuth registration and successful live key reads remain unverified. [Account tests](../../crates/usage/jackin-usage-provider-kimi/tests/account.rs) |
| MiniMax | Select the regional Token Plan key during Add Account. Jackin validates its model inventory before installation and stores the selected region with the credential. [Plan client](../../crates/usage/jackin-usage-provider-minimax/src/plan.rs) | The response supplies each model’s interval and weekly windows, window bounds, boost and remaining percentage. For ambiguous count fields, compare the reported percentage against both interpretations. A conflict beyond the official client's one-point tolerance leaves the count unknown. The model may be excluded from the plan even when weekly status alone indicates unlimited. [Count interpretation](https://github.com/MiniMax-AI/cli/blob/ae29aae57b05c2140c7ea6aba0a852763ffe7859/src/utils/quota.ts) · [tests](../../crates/usage/jackin-usage-provider-minimax/tests/plan.rs) |
| MiMo | The Token Plan key reads the selected subscription cluster. A regular key reads the separate account balance and preserves each amount in minor currency units. Jackin validates the corresponding product before saving. [Provider](../../crates/usage/jackin-usage-provider-mimo/src/lib.rs) · [cash balance](../../crates/usage/jackin-usage-provider-mimo/src/balance.rs) | Fixtures cover authenticated request shape, integer credits above 2⁵³, negative cash balances, zero, UTC billing periods, absent fields, invalid precision and wrong product. The daily bill and consumption endpoints are documented above. Their date-range reads remain pending. [Tests](../../crates/usage/jackin-usage-provider-mimo/tests/token_plan.rs) |
| Gemini | Enter a Google Desktop OAuth client ID, its optional client secret and an optional Cloud project ID. Jackin opens Google's consent screen, checks the loopback response, exchanges the code using S256 PKCE and reads both the account profile and the selected Code Assist project's quotas. Sign In Again reuses the registration and project and validates the new grant. [OAuth](../../crates/usage/jackin-usage/src/gemini_login.rs) · [connection and vault format](../../crates/usage/jackin-usage/src/onboarding/gemini_connection.rs) · [Google desktop app registration](https://developers.google.com/identity/protocols/oauth2/native-app) | Model/token buckets preserve a reported amount independently of its fraction. The grant identity includes Google subject and project. A Google account without an eligible or initialized Code Assist tier receives a setup error. A release-level OAuth client registration and live Code Assist access have not been verified. [Provider tests](../../crates/usage/jackin-usage-provider-gemini/tests/account.rs) · [loopback and reconnect tests](../../crates/usage/jackin-usage/tests/extension_connections.rs) |

The provider and connection tests ran against local HTTP fixtures. They do not require a browser login, actual account secrets or another agent's installation.
