### U12 (P6.1, from rewrite/reconciliation/U12.md)

This file records the preconditions of the approved P6.1 test plan (U12-1 to U12-12), the orchestrator decisions OD-1 to OD-10, and the choices the plan left open. The tests of `crates/jackin/tests/cli` and `crates/jackin/tests/process` rest on them.

## Preconditions U12-1 to U12-12

- U12-1. `jackin::run(AppEnv, Deps) -> ExitClass` is the only entry that tests use. `ExitClass::code()` lives in the library. `main` builds the system dependencies, runs `run`, and returns `ExitCode::from(class.code())`. It has no other logic.
- U12-2. `AppEnv` is `{ args, stdout, stderr, terminal: Option<Box<dyn Terminal>>, cwd: HostPath, config_path, cache_dir, env: EnvSnapshot, cancel }`. `stdin_is_tty` is gone: a terminal means a TTY. `Terminal` is an owned trait: `size() -> TermSize`, `enter_raw() -> io::Result<RawMode>` (the guard restores the mode when dropped), `read_line() -> io::Result<Option<String>>` (`None` is end of input, used by prompts), and `next_input() -> TerminalInput` (`Bytes`, `Resized`, `Closed`, used by attach and shell). Output of attach and shell is written to `AppEnv.stdout`, so the trait has no output method. `Deps` gains `limits: LaunchLimits`, because the library holds no timing constants. The library never reads the process environment, the working directory, or the home directory.
- U12-3. Exit codes: Ok 0, Failure 1, Usage 2 (clap's own), Refused 3, Cancelled 130.
- U12-4. Stdout carries data only: JSON, help, version, the plain `build` image ID, the `ls` names, the export refs, and the sandbox name and launch ID that `load` prints without a TTY. Errors, warnings, prompts, progress, the doctor report and the exit and detach lines go to stderr. Usage errors come from `Cli::try_parse_from` and are rendered into the `AppEnv` writers, so no clap code writes to the process streams or exits.
- U12-6. `jackin::locations(&EnvSnapshot)` derives every host location from `AppEnv.env` and `main` calls it. Config: `$XDG_CONFIG_HOME/jackin/config.toml`, else `ConfigStore::default_path($HOME)`. Cache: `$XDG_CACHE_HOME/jackin`, else `$HOME/.cache/jackin`. OpenShell registry: `$XDG_CONFIG_HOME/openshell`, else `$HOME/.config/openshell`. Engine socket: the `unix://` path of `DOCKER_HOST`, else `/var/run/docker.sock`. A `DOCKER_HOST` with another scheme is ignored. `HOME` and `XDG_*` must be absolute, and a missing `HOME` is an error.
- U12-7. A handler validates, plans and prompts before it calls `connect`. `connect` is lazy and never runs for `role`, `workspace`, `gateway`, `build`, or `account add` of a provider other than Codex. `doctor` passes the connect error to `GatewayAccess::Failed`.
- U12-12. Test rules of U8-A9 and U11-18 carry over: no comments, each test under 150 lines, `TestResult`, a 10 s guard, no paused tokio time, no argv or call-order assertions. The only text assertion is `stderr.contains(identifier)` for an identifier that the fixture supplied.

## Orchestrator decisions

- OD-1. `AppEnv` gains `cwd`, the terminal port, and the prompt source (U12-2).
- OD-2. The exit codes are U12-3.
- OD-3. `load` without a TTY launches, prints the sandbox name and the launch ID on one stdout line separated by a tab, exits Ok, and leaves attaching to `jackin attach`.
- OD-4. `jackin` with no subcommand prints help on stdout, with or without a TTY, until the console lands (U14).
- OD-5. Every `Cancelled` error and EOF at a prompt exit Cancelled. A cancel during attach detaches and exits Cancelled.
- OD-6. `doctor` fails when no gateway is chosen and names `jackin gateway add`.
- OD-7. There is no `JsonSchema` and no `schemars`. The JSON views carry `schema: 1` and tests pin their key sets.
- OD-8. See U12-4.
- OD-9. `ls` with a managed sandbox whose labels are unreadable exits Ok, names the sandbox on stderr, and leaves it out of the JSON.

## Records of the implementation

- `SystemClock` of `jackin-session` has no `Clock` implementation. `jackin` defines `HostClock` for `main` until the session crate lands one.
- API.md lists `Session::forget_account`. It is not in the landed session crate, so `account rm` calls `Session::gateway().delete_provider` itself (U12-9).
- `GatewayConnector::connect` returns `GatewayError`. `GrpcConnector` maps a `DiscoveryError` to `GatewayError::Unreachable` with the discovery message.
- The `Command::new` rule of the containers check flagged `Command::new(env!("CARGO_BIN_EXE_jackin"))` in `crates/jackin/tests/process`. `crates/jackin/tests/process` joins `COMPUTED_COMMAND_DIRS` and the K6 test in `crates/xtask/tests/repo_gates.rs` is amended in the same commit, as P5.2 did for `host.rs`. Another file of `crates/jackin` is still flagged.
- A paths argument may hold `..`. `HostPath::resolve` rejects a parent segment, so `jackin` resolves `..` and `.` lexically against `AppEnv.cwd` (`paths::absolutize`) before it builds a `HostPath`.
- `jackin-openshell` test `contract::shell_exit_code_cannot_hang_the_run` failed once in a full gate run under load (`left: Err("the shell exit code is not 3")`, `right: Err("the shell never ended")`) and passed on every rerun. It is not part of P6.1.
