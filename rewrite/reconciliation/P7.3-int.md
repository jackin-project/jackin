## Observed BuildKit behaviour (live)

- `COPY --from=layout` repairs hostile directories: a role that made all six directories sandbox-owned 1777 built with the final state root-owned 0755 (LP-1c d1).
- `COPY` does not replace an existing symlink at `jackin-start`, and it refuses to replace a directory with a file (`cannot replace to directory`). Both end in a failed build (LP-1c l1, l2), not a breach. The scan is the second layer for the symlink case.
- `--chown=root:root` is not resolved through the role passwd: a role that renumbered `root` to 1000 still got 0:0 files (LP-1d n1). The numeric `0:0` change is not needed.

## Differences from the plan

- T1.2 expects every pair to read `/trusted` + path, and checks that the stage `trusted` (FROM construct) copies that path from the build context or `--from=codex`.
- T2.1 sets the swap delay to a quarter of the measured control attempt, not a fixed 1.2 s, so a fast host still swaps mid-validation. The instrument gate asserts the state file did not change since the request. Line count is 200000. Measured on this host: green run 46.6 s at load 164 (control plus two swap attempts).
- The explicit-list rows of N4 live in `an_authored_read_write_list_refuses_every_path_that_names_the_root_or_aliases_it`; `role_check_refuses_each_gateway_violation_class` has no "port above 65535" row because jackin already refuses it before the gateway runs.
- N3g became `scan_never_passes_when_one_of_its_tools_is_missing`. The account checks use only shell builtins and `find`, so no new parser tool exists.
- The 1092-row and 780-row universes pin exact counts (1528 gateway-refused, 26 lexical-root-only, 630 accepted; 660 refused, 120 accepted), computed once by an independent Python model, not read from the implementation.

## Not covered

- Supplementary groups (`root:x:0:sandbox`, `disk`) are not checked by the I3 rules.
- An image symlink to `/` named in a `read_write` path is not detected by any lexical rule.
- The env file is held in a shell variable with no size bound (the agent can only starve its own sandbox).
- FIFOs and sockets in the image are not refused by I5.
