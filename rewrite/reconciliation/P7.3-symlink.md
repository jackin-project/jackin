## What changed

| Area | Change |
|---|---|
| `jackin-core` `FileSystem` | Two methods without defaults: `read_link(root, file)` returns the link text or a `LinkProblem` (`Symlink`, `NotALink`, `Missing`, `NonUtf8`); `write_symlink(path, target)` creates a link with exactly that text and fails with `AlreadyExists` on an existing path. |
| `StdFileSystem` | `read_link` walks below the root with `openat` and `O_NOFOLLOW` (shared `open_parent` with `read_regular`) and calls `readlinkat` on the parent fd. It never joins root and path into one string. `write_symlink` runs `symlink` on the blocking pool. |
| Ten implementors | Seven delegate (`SwapFs`, `SignalFs`, `CancelsOnRead`, both `CrashFs`, `GateFs`, `FaultFs`). `MemFs` and `RegistryFs` return `Unsupported`. |
| `jackin-image` `context.rs` | A listed symlink is staged as a symlink with the same text, never followed. The rule, checked on each link's own text: zero or more leading `..`, then one or more plain segments; the `..` count is at most the link's depth; everything else is `Escapes` naming the link. No chain resolution; a dangling target is accepted. `read_regular_file` still refuses links. |
| Mapping (J3) | leading symlinked component: `Symlink`; not a link: `NotARegularFile`; missing: `Missing`; non-UTF-8: `Escapes`; text that fails the rule: `Escapes`. |
| `jackin-session` `roles.rs` | The dirty-tree digest hashes, per entry, a fixed-width kind tag and exec byte before the length-prefixed name and content. A link hashes its target text under the link tag and no mode. A regular file hashes one byte, 1 when `mode & 0o111 != 0`. The raw mode is not hashed. A link or file that vanishes between `stat` and the second call is skipped. Every dirty digest changes once; no compatibility is kept. |
| `jackin-testkit` | `CapturedFile` is an enum (`File`, `Link`) with `file` and `link` constructors. `snapshot` records a link through `read_link` and never descends into a linked directory. Callers: `tests/host.rs`, `jackin-image/tests/image_io/buildx.rs`. |
| `Stack::with_fs` | Test support: builds the engine over a given `FileSystem`. |

5. Test A's "resolver rewrites `chain_a`" break reddens as `ContextEntry { chain_a, Escapes }`, because the resolved text `../AGENTS.md` is deeper than the link's depth. It is red for the stated reason (a chain was resolved).
