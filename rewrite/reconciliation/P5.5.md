## Deviations from plan v2

- `host.dock*.internal` is refused at policy parse by `gateway_refuses_shape` (a later label with `*` that is not exactly `*`), so it never reaches `engine_host_violations`. It moved to the "refused for another reason" row. The partial-label positive that does reach the overlap check is `*ost.docker.internal` (first label), and it is refused as `EngineHost`.
- Break 1c. Removing jackin's own `to_ascii_lowercase()` in `HostPattern::parse` stays green (`5 tests run: 5 passed`): the case fold that matters is inside `host_patterns_overlap` in `openshell-core`, which this repo cannot edit. The red break models a case-sensitive compare in jackin: literal hosts by string equality, wildcard hosts by overlap, and no lowercasing at parse.
- Break 1d (delete `check_engine_host`). Both halves of the CLI test go through `inspect`, and the `role check` loop runs first, so the `load` half is not red on its own. The `load` half is green-checked with `host.docker.internal` (see Green).
- The error type is `EngineHostViolation`, not `Vec<RuleKey>`, so the text can name the alias per rule.
- `EngineConfig` keeps public fields. The 2375 check sits at the two config entry points (parser and `add_gateway`); a value built in code, as the tests and the rig do, is not checked.
- Test B needs a delegating filesystem that records `max_bytes`. It is test-local (`tests/launch/cap_fs.rs`), a twelfth `FileSystem` implementor in the test tree, beside `StdFileSystem`, `MemFs` and the nine others.

## Accepted residuals (no test)

- IP-literal host. A role can name the gateway's LAN or bridge address; OpenShell gives an IP-literal host an implicit allowed IP (`proxy.rs:4061-4077`, `destination.rs:101-125`). A LAN-bound engine is reachable that way without the capability (the client key is still needed to use it). D24 recommends `127.0.0.1`.
- F2, second half. A port equal to the gateway endpoint port is not refused: jackin config does not hold the gateway endpoint, and the OpenShell gateway listens on more than one port. Low, hardening, not reproduced.
- F4 (the engine rule's binary match includes descendants of `/usr/local/bin/docker`) and F5 (the forbidden-tool scan works by name and execute bit). As recorded in the 2026-11-06T06:20:00Z row.
