## Method

For each row: `git clone --quiet https://...` (HTTPS; ssh denied), `git fetch origin`, then against `origin/main`:
- `git merge-base origin/main <br>` and `git rev-list --count <mb>..<br>`
- `git diff --name-only <mb> <br>` (2-dot) and `git diff --name-only origin/main...<br>` (3-dot)
- `git cherry origin/main <br>` (patch-id equality)
- per-path blob comparison vs `origin/main` tree: blob-equal / blob-differs / **absent from main**
- **absence in main's object history**: `git rev-list --objects origin/main` blob set (catches content deleted from main's *tree* but still present in main's *history*)
- **cross-ref uniqueness**: blob indexed across every `refs/remotes/origin/*` tip tree and each ref's full `rev-list --objects` history (catches content duplicated on another branch)
- file sizes (`git cat-file -s`), plus `git show`/`git ls-tree`/`git grep` spot checks

A path is counted **TRULY UNIQUE** only if its blob is absent from `origin/main`'s tree AND from `origin/main`'s object history AND from every other remote ref's history.
