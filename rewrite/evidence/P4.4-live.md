# P4.4 live evidence: power calls on a provisioning-failed sandbox

Date: 2026-11-02. Gateway `jackin-local` (openshell 0.1.6, vm driver). Workspace `jackin-b6`, created for this run and deleted at the end. Every call ran with stdin `/dev/null` under `perl -e 'alarm shift; exec @ARGV' <secs>`. Raw log: /private/tmp/claude-501/p44b6/b6.log.

Question (P4.4 testkit review, finding B6): what do Stop and Start return on a sandbox in `Error` with the `ProvisioningFailed` condition and no exit code, and does the phase change?

## Create with an image that does not exist locally

`openshell -g jackin-local sandbox create --workspace jackin-b6 --name jackin-b6-pf --from jackin.invalid/b6-missing:0000000000000000 --no-tty -- /bin/true`

```
Error:   × sandbox entered error phase while provisioning: ProvisioningFailed: failed
  │ to authenticate registry access for vm sandbox image 'jackin.invalid/b6-
  │ missing:0000000000000000': error sending request for url (https://
  │ jackin.invalid/v2/)
  Phase: Error
  Last exit code: -
    - Ready: False (ProvisioningFailed) - failed to authenticate registry access for vm sandbox image 'jackin.invalid/b6-missing:0000000000000000': error sending request for url (https://jackin.invalid/v2/)
```

The `jackin.invalid/` host also makes the gateway fail closed: the only registry request goes to the unresolvable host.

## Stop, twice: Internal error, phase unchanged

```
Error:   × code: 'Internal error', message: "stop sandbox failed: persist stop marker
  │ failed: No such file or directory (os error 2)"
stop exit=1
  Phase: Error
  Last exit code: -
```

The second Stop gives the same error and the same state.

## Start, twice: FailedPrecondition, phase unchanged (not Starting)

```
  │ execution', message: "sandbox must be Stopped, Suspended, Completed, or a
  │ failed main-process Error to start (current phase: Error); stop the
  │ sandbox before retrying start"
start exit=1
  Phase: Error
  Restart count: 0
```

## Delete: accepted

```
✓ Sandbox jackin-b6-pf deletion accepted; cleanup is pending
No sandboxes found.
✓ Deleted workspace jackin-b6
```

## Result for the fake gateway

On `Error{exit_code: None}` with `Provisioning::Failed`: `set_power(Stop)` fails with the `Internal` status class and leaves the sandbox unchanged; `set_power(Start)` fails with `FailedPrecondition` and leaves the phase `Error` (it does not move to `Starting`); delete succeeds. The only way forward from a provisioning-failed sandbox is delete.

# Upload to an absent sandbox

Date: 2026-11-02. Same gateway. A scratch git repository with one committed file at /private/tmp/claude-501/p44up/proj, run from its root. Log: /private/tmp/claude-501/p44up/up.log.

```
== 2026-11-02T08:40:07Z upload to absent sandbox, step 1 (filtered)
Uploading . -> sandbox:/sandbox/project
Error:   × code: 'Some requested entity was not found', message: "sandbox not found"

exit=1
== step 2 (.git, --no-git-ignore)
Uploading .git -> sandbox:/sandbox/project
Error:   × code: 'Some requested entity was not found', message: "sandbox not found"

exit=1
```

Both CLI calls exit 1 at once; neither hangs. The adapter maps the first non-zero exit to `Transfer { op: UploadFiltered, status: Exited(1), tail }` and does not run step 2.
