## V1 live: a tracked path under a symlinked parent (2026-11-02T19:51Z)

Script and log: /private/tmp/claude-501/p53-e10/run.sh and run.out. Workspace `jackin-e10`, sandbox from `jackin.invalid/minimal-role:1ca86b9020abf73e`, both deleted. In each case `creds/token.txt` was committed, then `creds` was replaced by a symlink to a host directory holding `HOST-SECRET-TOKEN`.

- Case A (`creds` not ignored): `git ls-files -co --exclude-standard` lists `creds`, `a.txt`, `creds/token.txt`. `openshell sandbox upload` exits 1: `sandbox upload failed: extraction exited with status 2: tar: creds/token.txt: Cannot open: Not a directory` / `tar: Exiting with failure status due to previous errors`. The sandbox holds `creds` as a symlink and no token.
- Case B (`creds` in `.gitignore`): the listing is `.gitignore`, `a.txt`, `creds/token.txt`. The upload exits 0, and `/sandbox/caseB/creds/token.txt` is a regular file holding `HOST-SECRET-TOKEN`. The CLI archive follows the symlinked parent, so a host file outside the project reaches the sandbox.

Case B makes V1 a confirmed leak through the real CLI. Jackin must refuse a listed path with a symlink in a leading component before any upload; the fake gateway must fail case A with exit 1 and the tar tail, and copy the outside bytes in case B, as the CLI does.

## Walker and import memory (E9, INT-MEM)

Date: 2026-11-03. macOS arm64, Apple Git-157 (git 2.54.0), release build of `crates/jackin-session/examples/export_memory.rs` (commit of unit U7). The probe starts the fake gateway and a real host repository, replaces the downloaded sandbox bundle with a crafted one (`Tap::replace_next_download`, the shared tap of the export tests) and runs `Session::export` with the production `LaunchLimits` (entry 512 MiB). It is rerunnable: `mise exec -- mbx +1.99.1 build --release -p jackin-session --example export_memory`, then `/usr/bin/time -l target/release/examples/export_memory honest` or `lying`. The figure that matters is `maximum resident set size` in bytes.

### Probe 1 (U7): a lying header that inflates to 1 GiB of zeros

The `lying` bundle holds one blob entry whose header declares 536,870,912 bytes (exactly the production entry cap, so the header check passes) and whose zlib stream inflates to 1,073,741,824 bytes of zeros (about 1 MiB compressed). The walker stops as soon as the stream passes the declared size.

```
honest: exported 1 branches                                    maximum resident set size 10944512, 10928128, 10944512
lying: refused: a pack entry declares 536870912 bytes and inflates to at least 536903680
                                                               maximum resident set size 28999680, 28688384, 29032448
```

Pass ceiling: 64 MiB (67,108,864 bytes). The refused run peaks at about 29 MB (honest baseline of the whole process: about 11 MB). The 18 MB between them are the generation of the bundle in the probe itself (the zlib encoder and its 1 MiB chunk) and the 64 KiB read and inflate buffers of the walker.

Red run, a mutant that inflates a whole entry into one growing `Vec` and does not compare with the declared size: the host `git` then runs on the bundle and fails (`pack has bad object at offset 12: inflate returned 1`), and the peak is 1,095,565,312 bytes (1.02 GiB), 38 times the fixed walker. This is the unbounded-inflate figure that the lying-header rows of `INT-W-ENTRY` cannot see in nextest.

### Probe 2 (U8): eight roots of 480 MiB through the real import

The `roots` bundle holds eight 15 MiB base blobs (a different fill byte each) and eight REF_DELTA entries, one on each base, each declaring a 480 MiB result built from 32 copy operations. The default limits accept it (480 MiB is under the 512 MiB entry cap and the sum of 3.75 GiB is under 64 GiB). `index-pack --stdin --strict` resolves all eight deltas; `update-ref` then fails because the header names a tip that this pack does not hold, which is the expected end of the probe. `maximum resident set size` is the largest of the example and the git child that it waited for.

```
roots (final code: --threads=1, core.bigFileThreshold=64m, core.deltaBaseCacheLimit=96m)
    526368768, 526434304
roots (mutant: index-pack --stdin --strict, no --threads=1 and no pins)
    4160913408
```

Pass ceiling: 768 MiB (805,306,368 bytes). The final import peaks at 526 MB (502 MiB), the figure of the design probe (527 MB). The mutant without the pins and with the default thread count peaks at 4.16 GB (3.88 GiB), the 4.17 GB of the design probe. `INT-IMP-PINS` pins the arguments that produce the difference; this probe is the only proof of the difference itself.
