## First run and the fix

The first run (ea6a629) failed J07 and J11 (`state is running 1 but the main process has no Codex child`), printed `cannot open /proc/370/environ: Permission denied`, and could not parse J12 on a PTY. Cause: the exec'd probe, with the same uid 1000 as `jackin-start` and Codex, gets EACCES on `exe`, `fd`, `environ`, `maps`, `io`, and `cwd` of those processes, while `stat`, `cmdline`, `comm`, and `status` stay readable (inferred: the Landlock ptrace domain; measured: the EACCES pattern). jq colored its output on a TTY. The probe now finds Codex by `comm` and parent pid from `/proc/<pid>/stat`, reads the tty from `tty_nr`, wraps every `/proc` read so the shell prints no error, runs jq with `-M`, and records in J08 which environments were unreadable.
