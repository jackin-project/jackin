3. Muse credential lifecycle: the gateway provider holds a 2026-11-06 token with no refresh metadata; `account add --from-host-login` cannot republish without an approved interactive macOS keychain read (30 s timeout inside jackin); no `account update`/provider republish path exists for OAuth-class accounts (A16's launch-time sync_provider covers static-key omp accounts only). T04 stays blocked until a keychain read is approved or muse grows a refresh token.
