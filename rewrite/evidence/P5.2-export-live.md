A fresh sandbox from a clean worktree reads `Exported`; the normal repository's sandbox reads `Unexported { uncommitted: true }` because the host's own uncommitted changes arrive in the sandbox as uncommitted work (D08). Export fetches only the branches whose tip differs from the host branch of the same name. A guarded purge refuses unexported work and leaves the sandbox; a forced purge deletes it; a repeated purge reports `AlreadyGone`.
