## Defects

1. `jackin doctor --json` does not exist. `error: unexpected argument '--json' found`, exit 2. The DESIGN.md CLI table lists `jackin doctor` with no `--json`, so this matches the table. The brief said "if the flag exists"; it does not.
2. Debug-formatted identifiers in user-facing errors:
   - `error: invalid role manifest at HostPath("/private/tmp/claude-501/p62/roles/unknown-key/jackin.role.toml"): unknown field mystery_field: unknown field mystery_field`
   - `error: invalid role manifest at HostPath("/private/tmp/claude-501/p62/roles/missing-field/jackin.role.toml"): missing field role.policy: missing field role.policy`
   - `error: missing file RepoPath("jackin.role.toml")`
   These print the raw Rust type names `HostPath(...)` and `RepoPath(...)`.
3. The manifest error message repeats its cause: `unknown field mystery_field: unknown field mystery_field` and `missing field role.policy: missing field role.policy`.
4. `jackin role check` on a path that does not exist reports `error: missing file RepoPath("jackin.role.toml")`. It does not say that the directory is missing, and it does not name the directory given.
5. `jackin ls` (no `--json`) on an empty gateway prints nothing to stdout and stderr, exit 0. No "no sandboxes" line. Minor.
6. Header note: no existing file in `rewrite/evidence/` begins with an SPDX header (`REUSE.toml` covers `**` with aggregate precedence). This file carries an HTML-comment header as the brief asked.

No secret, token, key material or certificate text appeared in any output (grep of the captured outputs for `BEGIN`, `token`, `secret` found nothing).
